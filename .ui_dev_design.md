# UI design — dxf-converter v2 (phase 3)

Source: `docs/workflow-analysis-2026-10-02.md` + `docs/plans/2026-10-02-v2-saved-scans-and-versions.md`.
Stack: vanilla JS/HTML/CSS in `app/static/` (no build step) — keep it.

## Primary use case

Turn a scan or a photo of a part/badge into a clean, to-scale DXF — and, when logged in, come back
to it later and keep improving it as numbered versions.

## Hero surface

The **editor canvas** (unchanged): geometry over the image, editing tools, right-hand panel.
Everything else is a short hop away and never competes with it.

## Layout and navigation

- **One top bar on every view:** app name (→ Home), file/scan name in the editor, and on the right
  the account area: `Log in` · `Sign up` when logged out (only if `/api/auth/status` says accounts
  are on; `Sign up` only if `signup` is on), or `<username> ▾` → Account, Admin (admins only),
  Log out.
- **Views:** Home, Editor, Admin. One path to each:
  - Home = drop zone + (logged in) "Your scans" library below it. The only place to open a saved
    scan. The editor's "New scan" button becomes **Home**.
  - Editor = today's editor plus a **Versions** panel section when a saved scan is open.
  - Admin = user table; reached only from the account menu.
- **Modals** (one component, used the same way everywhere): log in / sign up, save, confirm,
  account. Escape and backdrop close them; Enter submits; focus returns to the trigger.
- **Errors inline:** each panel has an error strip under the action that failed (drop zone,
  Detection, Export, Versions, dialogs, admin rows). Toasts only for success.

## Workflows (implementation order)

1. **Safe editing** — stateless export; Re-detect asks before discarding edits and is undoable;
   restart-aware messages.
2. **Editor feedback & scale** — inline errors, loading overlay, empty states, one scale control,
   missing Detection fields, export name from the file, one points count.
3. **Log in / sign up / log out** — account area, auth dialog, token handling, 401 → re-login →
   retry without touching the editor.
4. **Save current work as a scan** — Save from the editor (prompts login/sign-up first when
   anonymous, editor intact), name defaults from the file name, becomes a saved-scan session.
5. **Library & reopen** — Home lists scans (thumbnail, name, versions, latest label, updated),
   search + sort; open loads latest version with the image via authenticated blob; rename; delete.
6. **Versions** — Save version (label, note; parent automatic), version list in the editor, load
   another version (unsaved-edits guard), relabel/note, delete version; Re-detect/Export route to
   the saved-scan API.
7. **Compare** — pick another version: ghost overlay, opacity, A/B flip, stats with deltas,
   warning when scales differ.
8. **Account** — change password, delete own account (API + UI).
9. **Admin panel** — users with counts; delete content; delete user; reset password (shows a
   generated one once); promote/demote (API + UI).

## Workflow Requirements

### 1. Safe editing
- **Data:** current paths; whether there are unsaved hand edits (`S.dirty`).
- **Actions:** Download DXF (works with no server-side upload); Re-detect; Undo after Re-detect.
- **Empty:** Download with nothing → inline "Nothing to export — every path is hidden or deleted."
- **Error:** Re-detect when the server lost the image → inline under Re-detect: "The server
  restarted and lost the uploaded image. Your edits are still here and can be downloaded;
  re-upload the image to detect again." Export never fails for that reason.
- **Success:** download starts + toast "DXF downloaded"; Re-detect replaces paths and Undo
  restores the previous paths.

### 2. Editor feedback & scale
- **Data:** detection status; stats; settings incl. `threshold_value` (Fixed only), `upsample`
  (photo, Advanced); export layer name; export filename.
- **Actions:** set Largest dimension (one scale control); export.
- **Empty:** paths list with zero paths → "Nothing detected. Try lowering Min length or Border
  margin (scan) or picking an ink colour (photo)." per source.
- **Loading:** canvas overlay "Detecting…" with spinner; panel controls stay usable.
- **Error:** inline strips (upload errors on the drop zone, detect errors under Re-detect, export
  errors under Download).
- **Success:** status bar + toast. Export "Exports at W × H mm" line replaces "Scale factor".

### 3. Log in / sign up / log out
- **Data:** `/api/auth/status`, `/api/auth/me`, token + username in localStorage.
- **Actions:** Log in, Sign up (toggle in the same dialog), Log out.
- **Empty:** accounts off → no account area at all.
- **Error:** inline in the dialog: wrong password, username taken, password too short, too many
  attempts (429), sign-up off. Fields keep their values.
- **Success:** dialog closes, account area shows the name, Home shows the library; any request
  that was waiting on login is retried.
- **Expiry:** any authed call that gets 401 opens the login dialog over the current view with
  "Your session expired — log in again to continue"; on success it retries once.

### 4. Save current work as a scan
- **Data:** upload id, file name, settings, paths, hidden layers.
- **Actions:** Save (editor panel top). Logged out → auth dialog first, then the save dialog.
- **Fields:** Name (default: file name without extension), Label (optional), Note (optional).
- **Error:** inline in the dialog (storage off, upload gone after restart → offer re-upload,
  413 too large).
- **Success:** toast "Saved as v1", top bar shows the scan name, Versions section appears.

### 5. Library & reopen
- **Data:** `GET /api/scans`: thumbnail (authenticated blob), name, versions, latest label,
  updated.
- **Actions:** filter by name; sort (last updated / name / created); open; rename (inline);
  delete (confirm with name + version count).
- **Empty:** "No saved scans yet — drop a file above, then Save." Filter with no match: "No scans
  match ‘x’."
- **Loading:** skeleton cards.
- **Error:** inline strip above the grid with Retry.
- **Success:** open → editor with the latest version loaded; rename/delete update the grid
  immediately.

### 6. Versions
- **Data:** version list (number, label, note, created, paths/points/circles), which one is
  loaded, whether there are unsaved edits.
- **Actions:** Save version (dialog: label, note); load a version; edit label/note; delete a
  version (confirm; not the only one).
- **Empty:** n/a (a saved scan always has ≥1 version).
- **Error:** inline in the Versions section.
- **Success:** new version appears at the top and becomes current; toast "Saved v3".
- **Guard:** loading another version or going Home with unsaved edits asks first.

### 7. Compare
- **Data:** two versions' paths and stats; their `fit_mm`/`scale`.
- **Actions:** choose "Compare with" (list of other versions with labels); opacity slider; A/B
  flip (key `B`); exit compare.
- **Empty:** only one version → compare control disabled with "Save another version to compare."
- **Error:** inline if loading the other version fails.
- **Success:** ghost geometry (dashed, single colour) under the current; stats table with both
  columns and deltas; warning chip when scales differ.

### 8. Account
- **Data:** username, created date.
- **Actions:** change password (current + new + confirm); delete account (type username to
  confirm; warns it deletes all scans).
- **Error:** inline (wrong current password, too short, last admin can't delete).
- **Success:** toast "Password changed — other sessions signed out"; account deletion logs out
  and returns Home.

### 9. Admin panel
- **Data:** users: name, admin, created, scans, versions, "you".
- **Actions:** delete content; delete user; reset password (shows generated password once with
  a Copy button); make/remove admin.
- **Empty:** n/a (the admin is always listed).
- **Error:** inline per row (last admin, yourself).
- **Success:** row updates immediately; counts refresh.
- **Confirm:** every destructive action names the user and what will go.
